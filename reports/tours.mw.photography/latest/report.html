Security 6 issues

Medium Security

Browsers aren't told to always use the secure address

Where
/, /manas-kaziranga/, /iberian-lynx/, /pyrenees/, /iceland/
Browsers
live site

What we found

  • No Strict-Transport-Security header (GitHub Pages can't send custom headers; see the fix for the workaround or a host that can)

Why it matters

Without HSTS, a visitor's very first request can be sent unencrypted and redirected by an attacker on public Wi-Fi.

What to change Needs you

Make the host send this header on every page.

GitHub Pages can't send this header. Options:
1. Publish through Vercel or Netlify (both read headers from a file in the code), or
2. Put Cloudflare (free plan) in front of the domain and add the header there:
   Strict-Transport-Security: max-age=31536000; includeSubDomains

This site is hosted on GitHub Pages, which can't send security headers. It needs a host change (or Cloudflare in front), which is a decision for you.

Medium Security

No Content Security Policy

Where
/, /manas-kaziranga/, /iberian-lynx/, /pyrenees/, /iceland/
Browsers
live site

What we found

  • No CSP header or meta tag (GitHub Pages can't send custom headers; see the fix for the workaround or a host that can)

Why it matters

A CSP is a whitelist of where scripts may come from. If any bug ever lets someone inject a script, the CSP stops it from running. It's the main safety net against account-stealing attacks.

What to change Needs you

Add a Content Security Policy. Start with the report-only version below, check nothing breaks for a week, then switch the name to Content-Security-Policy.

GitHub Pages can't send this header. Options:
1. Publish through Vercel or Netlify (both read headers from a file in the code), or
2. Put Cloudflare (free plan) in front of the domain and add the header there:
   Content-Security-Policy-Report-Only: default-src 'self'; script-src 'self' https:; style-src 'self' 'unsafe-inline' https:; img-src 'self' data: https:; font-src 'self' https: data:; connect-src 'self' https:; frame-ancestors 'none'

Without header support, a CSP can also go in each page's <head>:
<meta http-equiv="Content-Security-Policy" content="default-src 'self'; script-src 'self' https:; style-src 'self' 'unsafe-inline' https:; img-src 'self' data: https:; font-src 'self' https: data:; connect-src 'self' https:">

This site is hosted on GitHub Pages, which can't send security headers. It needs a host change (or Cloudflare in front), which is a decision for you.

Where

What we found

  • 4.0s (target under 2.5s)

Why it matters

Largest Contentful Paint is when the biggest thing on screen (usually the hero image) appears. Google's target is under 2.5 seconds.

What to change Needs you

Make the images smaller (resize to the size they're shown at, WebP or AVIF, about 80% quality), load images below the first screen with loading="lazy", and let the main image load first with fetchpriority="high".

<img src="hero.webp" fetchpriority="high" alt="…">
<img src="later.webp" loading="lazy" alt="…">
